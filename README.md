# Visitor Pass Management System (MERN Stack)

A full-stack digital Visitor Pass Management System built with MongoDB, Express, React, and Node.js.

## Features
- JWT Role-Based Access Control (Admin, Security, Host, Visitor)
- Visitor Pre-Registration with Photo, ID Proof & OTP Verification
- Automatic QR Code Pass Generation & Printable PDF Badges
- Security Gate Check-In / Check-Out Scanner with Audit Logs
- Analytics Dashboard, Search/Filter & CSV Report Export

## Setup Instructions
1. Backend: cd backend -> npm install -> set MONGO_URI in .env -> npm run seed -> npm start
2. Frontend: cd frontend -> npm install -> npm run dev
